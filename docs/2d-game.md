# 2D game flow

**User goal:** See a live coding agent as a pet in the desktop village and open the agent by selecting the pet.

```text
Herdr or connected coding tool
  → Rust agent broker
  → public agent snapshot
  → Tauri WebView village
  → pet animation, label, movement, and interaction
```

1. The desktop app collects Herdr sessions and connected coding-tool events. The broker normalizes each live agent to an opaque ID, state, safe display label, and source. A validated Herdr-owned session appears once.
2. The village assigns an available pet appearance and reads its behavior pack. The current agent state selects visibility and either `idle` or `walking` movement. Standard uses the state's normal APNG; App-wide Ocean switches every bundled pet to its corresponding Ocean APNG (rowing for Working, damaged boat for Blocked, pennant for Completed, rainbow wave for Mayor Listening, trumpet for Mayor Speaking). When App is Standard, a bundled pet can individually choose Ocean instead. Idle and Unknown remain hidden for ordinary agents. The Mayor's visible walking/idle flow rows with the Working Ocean clip when not listening or speaking.
3. App Ocean draws the Living Coast: translucent rolling water, a bounded school of wandering fish, two floating edge lighthouses, buoys, bubbles, sparse kelp, and reflected foam, even if no agent pets are visible. App preferences still set water opacity and waterline height. A shared renderer clock drives the displayed contour, boat height and pitch, and paddle wakes; labels stay upright and agent movement rules do not change. All scenery is click-through. Settings pauses the desktop coast; Reduce Motion freezes the scenery and Ocean pet frames and levels boat pitch. Standard pet animations are unchanged. Standard remains transparent. A working pet travels across the strip and turns at screen edges. Blocked and completed pets stay in place. Names follow the visible pets. On macOS, the transparent pet strip remains visible above other apps' full-screen Spaces while letting clicks pass through outside pets. The village updates when the broker snapshot changes and removes a pet after the departure grace period.
   App Rainforest draws the original SVG forest in After Rain or Firefly mode, with bounded independently wandering butterflies or fireflies. A renderer presentation facade advances the theme renderers from the same village clock; no decorative layer owns agent state or an independent animation loop. Rainforest uses normal state APNGs and the same pet sizing, clip scaling, transparent-foot correction and ground baseline as Standard. The native strip meets the work-area bottom edge without an extra window margin, so painted scenery has no gap underneath. Decorations remain click-through and render with an empty village. Settings pause and Reduce Motion freeze the forest scenery; normal pet state/movement/focus rules remain unchanged.
   App Snowy adds the selected Alpine Cabin in Fresh Snow or Aurora Night mode, keeping Standard pet size and ground alignment. The common village clock advances bounded snowfall, ambient glow/smoke and a reusable pool of up to 128 fading shoe impressions. Only real walking displacement emits marks; idle, blocked, done, hidden, dragged or repositioned pets cannot create connecting trails. Snow opacity affects decoration, not pets/labels. Settings pause and Reduce Motion freeze snowfall and footprint aging. No new focus behavior or separate scenery animation loop is introduced.
   App Desert Oasis provides Palm Spring, Adobe Outpost and Lantern Caravan scenes, each in Golden Dunes or Moonlit Oasis. The same village clock drives a bounded set of near-ground blowing-sand ribbons, dust grains and spring ripples. Decorations pause with Settings, Reduce Motion and hidden state. Desert opacity affects scenery only; pets retain Standard geometry and animations. No desert footprints, new agent actions or native focus/window changes are introduced.
4. Clicking a pet asks Rust to focus the current agent. Rust revalidates its private route first. Herdr can focus the exact pane; a standalone connection can activate an already-running matching application. A local Codex Desktop session with a valid thread UUID can also open its exact conversation using Codex's deep link. Dragging a pet changes its position in the village.

**Other outcomes:** When there are no visible live agents, the village has no agent pets to draw. An unavailable or stale focus route does not launch or resume an agent. Settings can change the visible cast and behavior assignments.

**Focus implementation:** Read [Pet click-to-agent focus](pet-focus.md) before changing click handling or macOS activation. It records the confirmed direct-transition behavior, helper process boundary, panel activation workaround, and required regression checks.
