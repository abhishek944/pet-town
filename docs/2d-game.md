# Pet Street game flow

**User goal:** See a live coding agent as a pet in Pet Street and open the agent by selecting the pet.

```text
Herdr or connected coding tool
  → Rust agent broker
  → public agent snapshot
  → Tauri WebView village
  → pet animation, label, movement, and interaction
```

1. The desktop app collects Herdr sessions and connected coding-tool events. The broker normalizes each live agent to an opaque ID, state, safe display label, and source. A validated Herdr-owned session appears once. Each Pet Street window keeps the complete citizen roster and derives its own display selection only when rendering; Mayor, preferences and display updates never filter the stored roster again. Ordinary agents are dealt round-robin by sorted ID across displays, while the Mayor stays on the primary street.
2. The village assigns an available pet appearance and reads its behavior pack. The current agent state selects visibility and either `idle` or `walking` movement. Standard uses the state's normal APNG; App-wide Ocean switches every bundled pet to its corresponding Ocean APNG (rowing for Working, damaged boat for Blocked, pennant for Completed, rainbow wave for Mayor Listening, trumpet for Mayor Speaking). When App is Standard, a bundled pet can individually choose Ocean instead. Idle and Unknown remain hidden for ordinary agents. The Mayor's visible walking/idle flow rows with the Working Ocean clip when not listening or speaking.
3. App Ocean draws the Living Coast: translucent rolling water, a bounded school of wandering fish, two floating edge lighthouses, buoys, bubbles, sparse kelp, and reflected foam, even if no agent pets are visible. App preferences still set water opacity and waterline height. A shared renderer clock drives the displayed contour, boat height and pitch, and paddle wakes; labels stay upright and agent movement rules do not change. All scenery is click-through. Settings pauses the desktop coast; Reduce Motion freezes the scenery and Ocean pet frames and levels boat pitch. Standard pet animations are unchanged. Standard remains transparent. A working pet travels across Pet Street and turns at screen edges. When its harness supplies fresh output-token activity, a smoothed throughput multiplier adjusts the configured movement speed (zero through 2.5×; 1,800 tokens/minute equals 1×). Pi supplies an approximate five-second streaming meter; Codex supplies sampled reported counters. Fresh zero slows the pet to a stop. Missing, invalid, or stale telemetry returns to configured speed. Blocked and completed pets stay in place. Animation frame timing does not change. Names follow the visible pets. On macOS, transparent Pet Street remains visible above other apps' full-screen Spaces while letting clicks pass through outside pets. The village updates when the broker snapshot changes and removes a pet after the departure grace period.
   App Rainforest draws the original SVG forest in After Rain or Firefly mode, with bounded independently wandering butterflies or fireflies. A renderer presentation facade advances the theme renderers from the same village clock; no decorative layer owns agent state or an independent animation loop. Rainforest uses normal state APNGs and the same pet sizing, clip scaling, transparent-foot correction and ground baseline as Standard. The Pet Street window meets the work-area bottom edge without an extra window margin, so painted scenery has no gap underneath. Decorations remain click-through and render with an empty village. Settings pause and Reduce Motion freeze the forest scenery; normal pet state/movement/focus rules remain unchanged.
   App Snowy adds the selected Alpine Cabin in Fresh Snow or Aurora Night mode, keeping Standard pet size and ground alignment. The common village clock advances bounded snowfall, ambient glow/smoke and a reusable pool of up to 128 fading shoe impressions. Only real walking displacement emits marks; idle, blocked, done, hidden, dragged or repositioned pets cannot create connecting trails. Snow opacity affects decoration, not pets/labels. Settings pause and Reduce Motion freeze snowfall and footprint aging. No new focus behavior or separate scenery animation loop is introduced.
   App Desert Oasis provides Palm Spring, Adobe Outpost and Lantern Caravan scenes, each in Golden Dunes or Moonlit Oasis. The same village clock drives a bounded set of near-ground blowing-sand ribbons, dust grains and spring ripples. Decorations pause with Settings, Reduce Motion and hidden state. Desert opacity affects scenery only; pets retain Standard geometry and animations. No desert footprints, new agent actions or native focus/window changes are introduced.
   App **Rollercoaster** adds Low Rolling, Twilight Carnival, Firefly Gardens and Cloudline SVG ride modes. Each visible agent has an independent cart: working agents ride along the rail using existing token-driven travel, blocked agents stop with an input-station cue, and done agents settle with a finish cue. **Gold Mine** adds the native-SVG Carved Amber Cavern with a stationary working pick action, resting blocked tool and completion cart. **Tiny Railway** adds a shallow stone viaduct with working rail-fastening inspection, blocked secured tools/barricade and completed inspection card. When a bundled pet folder publishes the nine approved `activity-*.webp` action loops with its `activity.json` sidecar, the matching state plays that dedicated stationary loop instead of the state clip: the sprite keeps the sidecar's scale and is aligned by its measured support anchor (hips/seat for Rollercoaster, feet or grounded-knee support for Gold Mine and Tiny Railway), the detached pickaxe or wrench prop is left out because the sprite holds it, and Blocked and Completed loops animate in place while only Settings pause, Reduce Motion, hover pause or a hidden document freezes the frame. Pets without accepted sidecar art keep their state clips. Tiny Railway scales only the per-pet trolley, toolbox and attached hardware to the approved 25% about the native floor centre, so the wheels stay on the rail and the pet rests on the derived deck support while the viaduct, timber post, labels and pet artwork keep their size. Installed Pet Studio extensions keep their own clips and state assignments. **Rollercoaster height** (integer 50–146 px, default 88) applies the same bottom-anchored vertical affine scale to the whole SVG scenery and sampled rail. Ground and hanging carts and pets follow that rail without scaling their artwork; land reaches the bottom at every height. Separate **Gold Mine opacity** and **Tiny Railway opacity** (integer 0–100%, default 100%) fade scenery only, leaving actors, tools, carts, names and badges unchanged. Missing settings preserve the former appearance. Activity props use the common village clock, never change agent status or flow visibility, and remain click-through. Existing pet art, completed-pet preferences and per-pet size/opacity remain active. Settings, Reduce Motion and hidden state freeze props; Reduce Motion also freezes activity sprite frames. No fake resource amounts or task percentages are reported.
   App **Moonlit Canopy** replaces only the selected theme's bottom strip with a 310-logical-pixel right-edge window on each display's work area. Native placement and the display watcher share this theme-aware geometry; other themes keep their current full-width bottom height, including manual resizing. Each Street window remembers its prior bottom height in logical pixels while Canopy is selected and restores that height using the destination display scale on exit; 290px is only the fresh-window fallback. This geometry state is registered with the window, committed only after successful size placement, and removed when the window is destroyed. The canopy and vine fill the complete work-area height without top/bottom scene margins; only pet travel keeps endpoint clearance to avoid clipping. The accepted muted canopy, fungi, ferns, roots and sparse fireflies remain click-through, including with an empty village. **Canopy opacity** (integer 0–100%, default 100%) fades the scenery and decorative leaf nooks only, keeping pets, labels and interactions unchanged; Settings previews the draft and Apply persists it. The static vine uses `8*sin(y/93) + 1.76*sin(y/39)` in CSS pixels, so its mild wave never grows with display size. Bundled pets follow that actual curve upward with six genuine character-specific transparent poses at 150ms each, independently of configured/token-driven travel speed. Cat retains its accepted original art; other pets use their own generated art and measured grip anchors. It fades near the safe top and softly returns at the bottom; height is not task progress. Fresh-zero telemetry stops travel after the existing smoothing, while stale telemetry returns to configured speed. Blocked and completed pets hold their character's resting pose on an inward leaf nook. Custom pets without bundled climbing artwork retain their own appearance on nearby nooks, including while Working. Pet Studio extensions keep their own assigned clips and do not inherit bundled climbing art. Real status, completed hiding, label/appearance preferences, display-local cast partition and the complete roster remain intact. The existing renderer clock freezes the appropriate frames, travel and fireflies for Settings, Reduce Motion, document hiding and applicable hover pause. Crowding uses the usable vertical route instead of narrow window width. Names/status stay upright and inward; pet/name click targets exclude scenery. Theme exit removes side presentation and restores bottom geometry. Individual Ocean choices are preserved.
4. Clicking a pet asks Rust to focus the current agent. Rust revalidates its private route first. Herdr can focus the exact pane; a standalone connection can activate an already-running matching application. A local Codex Desktop session with a valid thread UUID can also open its exact conversation using Codex's deep link. Dragging a pet changes its position in the village: horizontal position for bottom themes, or path-relative height for Moonlit Canopy. A 4px two-dimensional displacement separates dragging from a click; cancellation and dragging never also focus an agent.

**Other outcomes:** When there are no visible live agents, the village has no agent pets to draw. An unavailable or stale focus route does not launch or resume an agent. Settings can change the visible cast and behavior assignments.

**Focus implementation:** Read [Pet click-to-agent focus](pet-focus.md) before changing click handling or macOS activation. It records the confirmed direct-transition behavior, helper process boundary, panel activation workaround, and required regression checks.
