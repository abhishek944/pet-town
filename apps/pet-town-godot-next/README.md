# Pet Town 3D island

This Godot project is the new Pet Town island. `npm run dev` launches the desktop app with this project. `npm run dev:workshop` launches the 3D scene alone for development. The former Godot project and its saved town remain separate.

Both Chill and Build use the same uneven terrain, shore, water, lighting, camera, settings, object library, and editor. Open the command palette with `/`, then enter `/chill` or `/build`. `/objects` opens the object browser; `/settings` opens Town Studio. Chill starts with 692 individually editable, fixed placements including trees, gardens, path tiles, buildings, lights, benches, and boats. Build starts with the terrain and water only. Its object library shows token-credit prices and purchase availability. In both modes, select an object to move, rotate, resize, delete, or undo changes.

The 53 catalog objects are independent models with ground pivots, selection colliders, measured footprints, and 3D previews. Solid land objects also have pet collision bodies; path tiles remain traversable. The 48 prior catalog IDs are included. The terrain is authored in Blender at `art/pet-town-next/world-base.blend`; fixed Chill placements are in `assets/chill_layout.json`. The playable imported scene is `scenes/world/WorldBase.tscn`. Pet navigation covers the meadow and shore and rebakes around solid objects when the layout changes. New layouts use separate `chill-layout.json` and `build-layout.json` files. The Build wallet is `~/.pet-town/build-wallet.json`. Set `PET_TOWN_TEST_DATA_DIR` to an empty scratch directory for isolated testing.

The live town bridge is active in Chill. Click a pet once to follow it with the camera; double-click to open its compact details panel. The panel shows its live status, source, assigned 3D character and camera state. Use **Stop following** or **Follow companion** to change the camera, and **Open in Herdr** (or **Open agent** for another source) to focus the current session through the desktop broker. **C** toggles manual pet control while following. Pets use the KayKit walk and idle animations while moving across ground and paving. Build hides live pets. Camera orbit, pan, zoom, and reset remain available in both modes.

Run `var/godot-runtime/Godot.app/Contents/MacOS/Godot --headless --path apps/pet-town-godot-next --script res://tests/workshop_smoke.gd` for the integrated smoke check. Additional `world_smoke.gd`, `movement_smoke.gd`, `catalog_assets_smoke.gd`, `modes_smoke.gd`, `agents_smoke.gd`, and `ui_smoke.gd` scripts live in `tests/`. The manual verification list is `var/test-checklist/workshop.md`.
