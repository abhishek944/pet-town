Before you move in

A few good
questions.

What is different in the browser demo?

It is a solo visit to the world. Live coding-agent companions and Mayor voice are part of the desktop app. Explore, build, take photos, and play with the native animals on desktop or touch devices.

What does Mayor need?

Mayor uses your configured OpenAI voice services and a Firstmate checkout you explicitly trust. Standard and Live mode use the same Firstmate primary. Voice service usage is billed separately.

Where does my world save?

World changes are stored in the current browser or desktop app. Browser and desktop saves do not transfer automatically.

Can I make my own 2D pets?

Import transparent APNG animations in Pet Studio, assign their behaviors, and save a local pet pack.

Which computers support the desktop app?

Pet Town currently provides macOS downloads for Apple Silicon and Intel Macs. The solo town runs in desktop and touch browsers with WebGL graphics support.
